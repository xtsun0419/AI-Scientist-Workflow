领域分析 / Field Analyst

上传论文后开始配置评审团队。

主编 / Editor-in-Chief

评估期刊匹配、原创性与整体质量。

方法学 / Methodology

评估研究设计、统计有效性与可复现性。

领域专家 / Domain

评估文献、理论框架与领域贡献。

跨学科视角 / Perspective

评估跨学科、实践与利益相关者视角。

反方评审 / Devil's Advocate

压力测试核心论证和最强反驳。

编辑综合 / Synthesizer

汇总评审意见并生成修改路线图。

请先在后端 app/config.json 中配置 API Key，然后上传论文初稿开始评审。具体评审意见默认用中文输出，题目、角色名和技术术语可中英并列。
